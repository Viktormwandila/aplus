About the curriculum and questions

The safety lesson is an original adaptation of Zambia’s CDC Physics syllabus, Form 1. Its source notes explain the teaching-module access limits and practical work that needs teacher supervision.

The practice set uses original examples covering themes in a 2017 Grade 10–12 revision booklet. It is a starter set, not all 152 numbered questions, an official ECZ paper or a complete new-curriculum course.

How progress and offline access work

Progress stays in this browser on this device. It does not sync across devices. Reset controls clear the relevant activity. Once a page has loaded online, supported browsers can keep it available offline. External source links still need internet.
