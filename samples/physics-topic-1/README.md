# Form 1 Physics — Introduction to Physics

A self-contained study lesson for Zambian Form 1 learners using short explanations and familiar examples. Aligned to CDC Physics Syllabus 2024, topic 1.1, printed pp. 2–3. Original content; teacher review pending.

## Study steps
1. What is Physics? Matter, energy, everyday examples and branches.
2. Laboratory safety: identify hazards and safer actions.
3. Waste: reduce, reuse, recycle and sort three waste types.
4. Apparatus: four interactive cards and a ruler-reading check.
5. Inquiry: a fair-test story and adjustable ramp model.
6. Practice: five questions with feedback, plus an explanation prompt.

## Use
Open index.html in a browser. All images, SVG diagrams, styles and JavaScript are embedded; the downloaded HTML works offline. No build, dependencies or account required. Browser storage saves the current step and answers when available. This is a study aid, not a secure exam system or a caching PWA.

## Visuals
Four Canva-generated 200px scene previews are displayed at 112px or smaller to avoid enlargement. The large hero was recreated at 1672×941 from a Canva reference using ChatGPT image generation, then compressed as WebP. Scientific diagrams are original SVG. Links to the four Canva originals are in the footer.

## Model
The adjustable ramp uses an ideal frictionless sliding particle, not a full rolling-car simulation. Assumptions and formula are in an optional disclosure. Learners only need to observe the trend; the formula is not required for Topic 1.1.
