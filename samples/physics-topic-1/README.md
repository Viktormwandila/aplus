# Form 1 Physics — Topic 1.1

Original interactive sample aligned to Zambia CDC Physics Syllabus (2024), Form 1, Introduction to Physics, printed pages 2–3. Teacher review pending. No private source documents or links are included.

## Run

Open index.html directly in a modern browser, or serve this directory with any static server. No build, dependencies, API keys or account needed. Progress and notes use browser localStorage when available. No tracking or network calls. Works with touch and keyboard; responsive styles cover phones, tablets and desktops. Offline reopening is possible from a downloaded file; this is not yet a caching PWA.

## Content

Laboratory safety hotspots; waste management; four apparatus cards; fundamental concepts and everyday applications; pendulum inquiry enrichment; three auto-scored questions and one self-marked extended response. Exam mode hides feedback until submission. It is a practice aid, not a secure assessment system. The ideal pendulum model uses T=2*pi*sqrt(L/9.81), for small oscillations, and is not a required formula for introductory Topic 1.1. Detailed measurement is Topic 1.2.3.

Alternatively merge the PR and incorporate the lesson into the repository's existing deployment.
